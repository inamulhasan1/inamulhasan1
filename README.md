## What I work on

**Storefront engineering**
Custom Liquid sections and page templates for a bilingual EN/Arabic store with full
RTL support. Modular sofa configurators, animated product diagrams, size guide
templates, rewards pages. Everything ships against a fixed design system with
section-scoped CSS, so components stay isolated and the theme does not accumulate
global overrides.

**Search visibility**
Structured data and schema markup across product, collection, and location entities.
Recent work included auditing the store's JSON-LD and resolving a syntax error plus a
duplicate FurnitureStore block that was fragmenting entity signals. Alongside
conventional SEO I optimise for answer engines and AI search, which rewards a
different content shape: specific, factual, and cleanly parseable.

**Growth and lifecycle**
Meta and Google paid media, GA4, and lifecycle automation through Klaviyo and
Omnisend. Reporting runs through MCP-connected tooling so campaign, catalogue, and
search console data can be queried together instead of reconciled by hand.
